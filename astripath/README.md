# 智学星枢 AstriPath · 2026 Qoder 高校创造力大赛参赛版本

> **〖StudyHack〗智学星枢：一个能够持续理解学生、规划学习路径的 AI 导师**
>
> 公网演示地址：**https://astripath-k78u5s6qgf1.qoder.zone**（无需登录，打开即用）

智学星枢（AstriPath）是一款面向高校学生的 AI 个性化学习系统。它解决的传统 AI 学习工具的核心短板是：**只会回答问题，却无法持续理解学生**。

学生进入系统后，通过课程诊断建立个人知识画像；系统根据知识点掌握情况生成个性化学习计划，并通过 AI 导师、针对性练习和学习反馈持续调整后续学习任务。它不仅能回答学生的问题，还能根据学生的学习表现决定下一步应该学什么。

**学习闭环：学习诊断 → 知识画像 → 个性化规划 → AI 辅导 → 针对性练习 → 学习效果反馈 → 动态调整计划。**

## 版本形态（重要）

竞赛版本**直接采用原版智学星枢（EduMind）的应用与可视化**（深色太空主题、3D 知识宇宙、3D 知识树、多智能体编排枢纽等），在其上叠加**演示模式**实现公网无登录体验：

| 层 | 内容 |
|---|---|
| 应用外壳 | 原版 EduMind Web 应用（Vue 3 + Vite + Three.js/PixiJS 3D 可视化），顶部导航保持原版栏目（首页/画像生成/学习路径/学习资源/智能评估/反向更新/设置） |
| 演示模式 | `src/demo/`：免登录种子会话、`/api/*` 本地模拟层（画像/学习路径/评估/导师问答/资源/证据）、演示状态模块（localStorage 持久化） |
| 竞赛闭环 | 新增 5 个视图，沿用原版设计语言：`/diagnosis`（8 题知识点诊断）、`/knowledge-profile`（3D 知识树画像）、`/plan`（7 天计划）、`/practice/:kpId`（针对性练习）、`/report`（学习报告）；导师复用原版「画像生成」对话视图 |
| 共享逻辑 | `astripath/src/logic` + `astripath/src/data`：确定性判分/掌握度/计划/导师检索与演示课程数据（从正式工程的 `server/study` 规则移植） |
| 入口 | 首页顶部「五分钟，体验 AI 如何改变一个学生的学习过程」横幅 → 立即体验 |

## 五分钟评委体验流程

1. 打开公网链接，自动进入原版首页（无需注册登录），点击「**立即体验**」。
2. 完成 8 道《Python 数据分析基础》诊断题（约 3 分钟），查看各知识点正确率与逐题解析。
3. 查看知识画像：3D 知识树按先修关系展示掌握度、薄弱点分组、变化记录。
4. 在「画像生成」页向 AI 导师提问薄弱知识点，查看讲解、示例、常见错误与课程引用依据。
5. 完成针对性练习，查看掌握度变化与自动重新生成的学习计划，最后到学习报告查看前后对比。

## 关键设计决策

| 决策 | 理由 |
|---|---|
| 竞赛版 = 原版应用 + 演示模式 | 用户要求沿用原版界面与可视化；同时满足任务书「优先复用已验证功能」「不推翻原有架构」 |
| 免登录种子会话 | 原版 Web 端路由守卫只校验 localStorage 会话，演示模式启动时写入演示学员会话 |
| `/api/*` 本地模拟层 | 无后端公网演示；未覆盖端点返回 404 触发原版视图自带的本地回退（原版就设计了降级） |
| 掌握度规则移植自正式工程 | `server/study/profile-updater.js` 证据驱动规则（证据门槛/稳定区间/变化上限/证据留痕） |
| AI 导师为演示模式 | 无 API Key 且密钥不得进前端；预置课程知识库检索，全界面明示，每个回答附引用依据 |
| 资源裁剪压缩 | Qoder Sites 单产物 50MB 限制：PNG→JPEG、行星模型子集、agenthub 模型 meshopt 21.8MB→2MB |

## 安全与合规声明

- 不包含任何 API Key、管理员接口、真实学生信息、支付流程。
- 所有演示数据（课程、题目、讲解）均为虚构样本，界面标注「示例数据」。
- 掌握度为**演示评估值**，不是经过真实用户实验验证的学习能力测量。
- AI 导师回答来自预置课程知识库检索（演示模式），标注引用依据；超范围问题明确降级，不编造答案。
