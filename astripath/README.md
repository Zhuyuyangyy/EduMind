# 智学星枢 AstriPath · 2026 Qoder 高校创造力大赛参赛版本

> **〖StudyHack〗智学星枢：一个能够持续理解学生、规划学习路径的 AI 导师**
>
> 公网演示地址：**https://astripath-k78u5s6qgf1.qoder.zone**（无需登录，打开即用）

智学星枢（AstriPath）是一款面向高校学生的 AI 个性化学习系统。它解决的传统 AI 学习工具的核心短板是：**只会回答问题，却无法持续理解学生**。

学生进入系统后，通过课程诊断建立个人知识画像；系统根据知识点掌握情况生成个性化学习计划，并通过 AI 导师、针对性练习和学习反馈持续调整后续学习任务。它不仅能回答学生的问题，还能根据学生的学习表现决定下一步应该学什么。

**学习闭环：学习诊断 → 知识画像 → 个性化规划 → AI 辅导 → 针对性练习 → 学习效果反馈 → 动态调整计划。**

## 五分钟评委体验流程

1. 打开公网链接，点击「立即体验」（无需注册登录）。
2. 完成 8 道《Python 数据分析基础》诊断题（约 3 分钟），查看各知识点正确率与解析。
3. 查看知识画像：薄弱知识点分组、掌握度雷达、可解释的变化记录。
4. 在 AI 导师页针对薄弱知识点提问，查看讲解、示例与课程引用依据。
5. 完成针对性练习，查看掌握度变化与自动重新生成的学习计划，最后到学习报告查看前后对比。

## 快速开始

```bash
cd astripath
npm install
npm run dev          # 本地开发（默认 http://localhost:5173）
npm run build        # 类型检查 + 生产构建 -> dist/
npm test             # 44 个单元测试（node:test）
npm run test:e2e     # 12 个 E2E（需先 build 并启动 vite preview）
```

## 关键设计决策

| 决策 | 理由 |
|---|---|
| 独立静态前端，无后端 | 原工程后端依赖 MySQL + 服务端会话 + LLM Key，不适合公网无登录演示（见 `docs/AUDIT_REPORT.md`） |
| 确定性算法，无随机性 | 判分、掌握度、计划生成全部可复现、可单测；相同输入必定产生相同计划 |
| 掌握度规则移植自原工程 | `server/study/profile-updater.js` 的证据驱动规则（证据门槛/稳定区间/变化上限） |
| AI 导师为演示模式 | 无 API Key 且密钥不得进前端；采用预置课程知识库检索并**全界面明示**，不伪装实时模型 |
| localStorage 持久化 | 设备本地存储，附重置演示按钮；隐私模式下降级为内存存储并提示 |

## 安全与合规声明

- 不包含任何 API Key、管理员接口、真实学生信息、支付流程。
- 所有演示数据（课程、题目、讲解）均为虚构样本，明确标注「示例数据」。
- 掌握度为**演示评估值**，不是经过真实用户实验验证的学习能力测量，界面与文档均已声明。
- AI 导师回答来自预置课程知识库检索，每个回答标注引用依据；超范围问题明确降级，不编造答案。
