# 项目概览 · PROJECT_OVERVIEW

## 1. 产品定位

**智学星枢（AstriPath）** — AI-Powered Personalized Learning System

口号：**让每个大学生都有一个真正懂自己的 AI 导师。**

面向高校学生的 AI 个性化学习系统。核心理念：AI 不应该只是回答学生的问题，而应该知道学生哪里不会、为什么不会，以及下一步应该学什么。

## 2. 解决的痛点

| 传统 AI 学习工具的不足 | 智学星枢的方案 |
|---|---|
| 学生不知道自己具体哪里不会 | 知识点级诊断，输出逐知识点的掌握度画像 |
| AI 回答问题后不持续跟踪掌握情况 | 练习结果按证据规则更新掌握度，全程留痕 |
| 学习计划固定，缺乏动态调整 | 掌握度变化即触发计划重新生成，并提示变化内容 |
| 练习与薄弱点之间缺乏关联 | 练习题库按知识点绑定，计划与画像双向驱动 |
| 缺乏完整的学习效果反馈机制 | 学习报告展示前后对比、变化流水与下一步推荐 |

## 3. 功能模块（P0 全部实现）

| 模块 | 路由 | 核心能力 |
|---|---|---|
| A 学习首页 | `/` | 欢迎界面、当前课程、总体掌握度、今日任务、学习进度、AI 导师入口、立即体验 |
| B 学习诊断 | `/diagnosis` | 8 道诊断题覆盖 5 个知识域；逐题知识点标签；自动判分；逐知识点正确率；知识画像生成 |
| C 知识画像 | `/profile` | 已掌握/学习中/需加强分组卡片；掌握度雷达；最近测试；练习数量；推荐学习内容；变化流水；计算规则说明 |
| D 个性化学习计划 | `/plan` | 7 天计划；薄弱优先 + 先修约束；推荐理由可解释；完成打卡；画像变化后自动重规划 |
| E AI 智能导师 | `/tutor` | 课程知识库问答；薄弱点讲解；代码示例；常见错误；下一步练习推荐；引用依据；演示模式明示 |
| F 针对性练习 | `/practice/:kpId` | 题目绑定知识点；即时判分；正确答案与解析；成绩记录；支持重练 |
| G 学习反馈 | `/report` | 掌握度更新、总体进度、学习前后对比、计划调整、下一步推荐 |

附加：`/course` 我的课程（课程介绍 + 先修知识图谱 + 知识点清单）。

## 4. 演示课程

《Python 数据分析基础》（示例数据）：8 个知识点，先修关系如下。

```text
Python 基础与数据类型 (py-basics)
├── NumPy 数组操作 (numpy-basics)
├── Pandas 数据读取 (pandas-io)
│   ├── 缺失值处理与数据清洗 (pandas-clean)
│   │   ├── GroupBy 分组聚合 (groupby-agg)
│   │   └── 数据可视化 (viz-basic)
│   ├── 数据筛选与变换 (pandas-select)
│   └── 数据合并与连接 (merge-concat)
```

配套内容：8 道诊断题（每题 1 个知识点）、24 道练习（每知识点 3 题）、8 张导师知识卡（讲解 + 示例 + 常见错误 + 课程资料引用）。

## 5. 技术栈

Vue 3.5 + Vue Router 4 + Pinia 2 + TypeScript 5.4 + Vite 6 + ECharts 6，无后端、无数据库、无外部 API 依赖。测试：node:test（43 单测）+ Playwright（11 E2E）。

## 6. 与正式产品的关系

- 正式产品：`EduMind`（Vue3 SPA + Node 后端 + MySQL + DeepSeek RAG + Capacitor 移动端），位于本分支未改动。
- 竞赛版本：独立静态应用，复用正式产品的数据组织方式与**证据驱动的画像更新规则**（`server/study/profile-updater.js`、`server/study/scoring.js`），按任务书要求与正式产品隔离。
