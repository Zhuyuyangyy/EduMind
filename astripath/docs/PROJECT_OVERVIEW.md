# 项目概览 · PROJECT_OVERVIEW

## 1. 产品定位

**智学星枢（AstriPath）** — AI-Powered Personalized Learning System

口号：**让每个大学生都有一个真正懂自己的 AI 导师。**

面向高校学生的 AI 个性化学习系统。核心理念：AI 不应该只是回答学生的问题，而应该知道学生哪里不会、为什么不会，以及下一步应该学什么。

## 2. 解决的痛点

| 传统 AI 学习工具的不足 | 智学星枢的方案 |
|---|---|
| 学生不知道自己具体哪里不会 | 知识点级诊断，输出逐知识点的掌握度画像 |
| AI 回答问题后不持续跟踪掌握情况 | 练习结果按证据规则更新掌握度，全程留痕 |
| 学习计划固定，缺乏动态调整 | 掌握度变化即触发计划重新生成 |
| 练习与薄弱点之间缺乏关联 | 题库按知识点绑定，计划与画像双向驱动 |
| 缺乏完整的学习效果反馈机制 | 学习报告展示前后对比与下一步推荐 |

## 3. 版本形态

竞赛版本 = **原版智学星枢应用 + 演示模式**（按用户要求沿用原版界面与可视化）：

- 应用外壳：原版 EduMind Web 应用（深色太空主题、Hero 星座、知识宇宙、3D 知识树、多智能体编排枢纽、AI 虚拟导师舱），顶部导航保持原版栏目；
- 演示模式：免登录种子会话 + `/api/*` 本地模拟层 + localStorage 演示状态；
- 竞赛闭环：5 个新视图（诊断/画像/计划/练习/报告）沿用原版设计语言，从首页「立即体验」横幅进入；
- AI 导师：复用原版「画像生成」对话视图，由预置课程知识库检索供数（演示模式，附引用依据）。

## 4. 功能模块（P0 全部实现）

| 模块 | 入口 | 核心能力 |
|---|---|---|
| A 学习首页 | `/home` | 原版首页全可视化 + 竞赛入口横幅（立即体验/查看演示课程/闭环流程） |
| B 学习诊断 | `/diagnosis` | 8 道诊断题覆盖 5 个知识域；逐题知识点标签；自动判分；逐知识点正确率；画像生成 |
| C 知识画像 | `/knowledge-profile` | 3D 知识树（先修关系 + 掌握度状态）；薄弱点分组；变化记录；计算规则说明 |
| D 个性化学习计划 | `/plan` | 7 天计划；薄弱优先 + 先修约束；推荐理由可解释；完成打卡；画像变化后自动重规划 |
| E AI 智能导师 | `/dialogue`（画像生成） | 课程知识库问答；薄弱点讲解；代码示例；常见错误；下一步练习推荐；引用依据；演示模式明示 |
| F 针对性练习 | `/practice/:kpId` | 题目绑定知识点；即时判分；正确答案与解析；成绩记录；支持重练 |
| G 学习反馈 | `/report` | 掌握度更新、总体进度、学习前后对比、计划调整、下一步推荐 |

附加：原版「智能评估」驾驶舱在演示模式下展示诊断/练习驱动的评估仪表。

## 5. 演示课程

《Python 数据分析基础》（示例数据）：8 个知识点，先修关系如下。

```text
Python 基础与数据类型 (py-basics)
├── NumPy 数组操作 (numpy-basics)
├── Pandas 数据读取 (pandas-io)
│   ├── 缺失值处理与数据清洗 (pandas-clean)
│   │   ├── GroupBy 分组聚合 (groupby-agg)
│   │   └── 数据可视化 (viz-basic)
│   ├── 数据筛选与变换 (pandas-select)
│   └── 数据合并与连接 (merge-concat)
```

配套内容：8 道诊断题（每题 1 个知识点）、24 道练习（每知识点 3 题）、8 张导师知识卡（讲解 + 示例 + 常见错误 + 课程资料引用）。

## 6. 技术栈

Vue 3.5 + Vue Router 4 + Pinia 2 + TypeScript 5.4 + Vite 6 + Three.js/PixiJS/ECharts；演示模式无后端依赖，数据存 localStorage。测试：node:test（44 逻辑单测 + 278 原工程回归）+ Playwright（10 E2E + 12 线上验收）。

## 7. 与正式产品的关系

- 正式产品：`EduMind`（Vue3 SPA + Node 后端 + MySQL + DeepSeek RAG + Capacitor 移动端）。
- 竞赛版本：同一代码库的 `competition/qoder-2026-studyhack` 分支，复用正式工程的判分/画像规则（`server/study/`）与全部界面可视化；演示模式相关改动集中在 `src/demo/`、5 个闭环视图与首页横幅，其余原版代码未改动。
