## 4. 测试期间发现并修复的问题

1. **计划算法缺陷**：薄弱知识点被先修链上无关知识点挤占 → 重写选点/排序算法（薄弱优先 + 先修闭包 + 链连续性），补充回归单测。
2. **导师检索误匹配**：长关键词子串匹配导致错误命中、单词命中低于阈值导致漏匹配 → 重构评分函数，补充回归单测。
3. **诊断结果页分支错误**：提交后展示历史状态而非本次结果（v-else-if 顺序）→ 修复并 E2E 覆盖。
4. **练习证据未留痕**：练习未改变掌握度时「累计练习」与「最近测试」不更新 → 修复为证据必留痕，补充单测 + E2E 回归。
5. **模板函数引用错误（重建后）**：视图中把导入的函数当值用（`demoIsDiagnosed` 恒真）导致答题页不显示 → 改为函数调用。
6. **状态非响应式（重建后）**：演示状态存于普通模块变量，计划打卡后界面不更新 → 增加响应式版本号，所有派生读取经 `getDemoState()`。
7. **导师问答请求体形态不匹配**：对话 composable 发送 `messages` 数组而非 `message` 字段 → mock 兼容两种形态。
8. **Live2D 桌宠移动端遮挡**：浮动 canvas 拦截底部按钮点击（真实 UX 缺陷）→ 演示模式预置关闭桌宠；同时补充 `scroll-padding-top` 修复固定顶栏遮挡。

问题 1-4 由自动化测试暴露；5-8 由构建后人工走查发现，均有回归覆盖。

## 5. 已知限制（如实说明）

- AI 导师为**演示模式**（预置课程知识库检索），非实时大模型调用；原版的 DeepSeek 链路因竞赛版无后端、无 API Key 未接入，这是任务书允许的降级路径（已明示）。
- 数据存于浏览器 localStorage，**不会跨设备同步**；隐私模式下降级为内存存储。
- 掌握度为演示评估值，非真实学习能力测量（界面与文档均已声明）。
- AgentHub iframe 的 3D 模型经 meshopt 压缩（21.8MB→2MB）并打解码器补丁；若运行环境无法加载 CDN 版 three.js，该区块显示其静态界面（其余功能不受影响）。
