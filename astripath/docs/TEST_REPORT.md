## 4. 测试期间发现并修复的问题

1. **计划算法缺陷（真实产品缺陷）**：薄弱知识点被先修链上无关知识点挤占（掌握度 10 的 pandas-clean 排到第 5 天之后）。修复：选点改为「最薄弱点 + 先修闭包」选择，排序增加「解锁链上后续薄弱点」优先的链连续性规则，并补充 3 个回归单测。
2. **导师检索误匹配（真实产品缺陷）**：长关键词子串匹配导致「loc 和 iloc 的区别」误命中 Python 基础卡片；单词命中低于阈值导致「groupby 的执行过程」未命中。修复：关键词改为整体命中查询，标题/知识点名/正文分级加权，补充回归单测。
3. **诊断结果页分支错误（真实产品缺陷）**：提交诊断后展示「历史诊断」而非本次结果（v-else-if 顺序问题）。修复并补充 E2E 覆盖。
4. 若干 E2E 测试脚本自身问题（选择器歧义、错误页面断言、不匹配定位器）——已修复，非产品缺陷。

## 5. 已知限制（如实说明）

- AI 导师为**演示模式**（预置课程知识库检索），非实时大模型调用；界面多处明示，不伪装模型能力。
- 数据存于浏览器 localStorage，**不会跨设备同步**（任务书 §5.4 已声明该限制）；隐私模式下退化为内存存储，界面会提示。
- 掌握度为演示评估值，非经过真实用户实验验证的学习能力测量；界面与文档均已声明。
- T01/T12 的公网访问验证需在 Qoder Sites 部署完成后复核（见部署记录）。
