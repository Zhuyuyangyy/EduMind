# 用户指南 · USER_GUIDE

## 评委五分钟体验路径

### 第 1 步：进入系统（10 秒）

打开 **https://astripath-k78u5s6qgf1.qoder.zone**。无需注册、登录或填写任何个人资料。点击「**立即体验**」。

### 第 2 步：完成学习诊断（约 3 分钟）

系统进入《Python 数据分析基础》演示课程的 8 道诊断题，覆盖 Python 基础与数据类型、NumPy 数组操作、Pandas 数据读取、数据清洗、数据筛选、分组聚合、数据可视化、数据合并。

- 逐题选择选项，可用顶部题号跳转修改；
- 完成后点击「提交答卷并生成知识画像」；
- 结果页展示：总得分、**各知识点正确率**、初始掌握度（演示评估值）与逐题解析。

### 第 3 步：查看知识画像（约 40 秒）

- 总体掌握度环 + 已掌握/学习中/需加强统计；
- 知识点掌握度雷达图；
- 按状态分组的知识点卡片：掌握度、最近测试、练习数量、推荐学习内容；
- 「掌握度变化记录」：每一次变化的时间、幅度与**原因**；
- 「掌握度是怎么算出来的？」：完整的计算规则说明。

### 第 4 步：体验 AI 导师（约 1 分钟）

页面顶部有黄色「演示模式说明」横幅：当前回答来自预置课程知识库的确定性检索，不是实时大模型生成。

- 点击推荐问题，或输入课程相关问题（如「什么是广播？」）；
- 回答包含：概念讲解、代码示例、常见错误、推荐练习、**引用依据**（课程资料出处 + 检索命中词项）；
- 超出课程范围时会明确告知，不会编造答案；
- 「针对你的薄弱知识点」区域提供薄弱点快捷练习入口。

### 第 5 步：完成针对性练习并查看反馈（约 1 分钟）

- 从计划页「开始练习」或画像卡「去练习」进入某知识点的练习（3 题）；
- 每题选择后**立即判分**并显示正确答案与解析（不可改答）；
- 提交后显示：本次正确率、**掌握度变化（前 → 后）及原因**、累计练习；
- 点击「查看更新后的学习计划」：计划已按新画像重新生成，页面顶部提示变化内容；
- 最后进入「学习报告」：学习前后对比、下一步推荐、学习流水、闭环说明。

## 重置演示

左侧导航底部「**重置演示**」按钮（需确认）：清空全部学习记录（诊断、画像、计划、对话），恢复初始演示状态。数据仅存于本机浏览器，不会同步到其他设备。

## 常见问题

- **数据存在哪里？** 仅本机浏览器 localStorage；清除浏览器数据或重置演示后会恢复初始状态。
- **为什么 AI 导师的回答有时「不智能」？** 演示模式使用预置课程知识库检索，只覆盖《Python 数据分析基础》课程内容，超范围问题会明确告知。
- **掌握度 75 分是什么意思？** 诊断正确率 100% 也只记 75 分（避免一题定生死），后续通过练习提升；这是演示评估值，不是真实学习能力测量。
