# 移动端首次体验与阅读优化

用户确认采用页面评估中的四项改进：缩短首次引导、提高手机字号、收敛玻璃装饰、明确成长页的下一步行动。

## 实现范围

1. 六张了解卡片独立保存学习偏好，完成后回到首页；首页展示目标并提供带入目标的导师入口。完整建档仍可选，不自动生成能力分数。
2. 从已完成卡片进入建档时，将已采集内容收起为可修改的摘要，仅展示其余需求；最后明确确认自评后调用现有画像与路径接口。传统四步问卷与导师规划入口保留。
3. 卡片正文及选项使用 14px，辅助文字至少 12px；首页、导航和通用徽标同步提高辅助字号。减弱背卡旋转、白边与阴影。
4. 成长页顶部提供真实路径主题对应的练习入口、导师入口和累计练习摘要。缺少路径或画像时提供对应行动，不用累计统计冒充本周增长。
