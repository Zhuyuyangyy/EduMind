## 数据边界

面板、宠物、笔记目录元数据在后端缺少对应接口时，按 API 来源及账号隔离保存在本机。宠物奖励仅消费已完成的服务器练习会话、达到有效时长的已结束服务器专注记录，或服务器已保存的清单自报完成（明确标记），以事件 ID 记账、重复读取不重领；这不提供跨设备奖励对账或防篡改保证。个人配置和原业务数据分别标明本机/服务器保存范围。

现有判分只支持真实题库的单选题。其他题型提供明确标识的本机自测练习与人工自评，不提交为服务器成绩。知识节点没有可归因练习证据时显示“证据不足”，不从路径估计生成精确能力分数。

## 界面意图

面向课间或晚间打开 App 的大学生与自主学习者，首先开始一段可完成的学习，再从真实结果安排下一步。围绕目标、轨迹、知识节点、原文、提取练习与陪伴组织界面。采用深蓝底、浅墨蓝表面、青蓝操作、柔紫关系与暖金奖励；原创“星航小伙伴”通过耳形、头盔轨道与成长徽记形成品牌特征。用可执行面板替代装饰仪表盘，用可定位知识关系替代无业务含义的宇宙动画，用本机成长账本替代虚构学习进度。
