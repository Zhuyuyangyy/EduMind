# 智学星枢品牌图标设计

## 方向

采用“星枢六边形”：六边形代表中枢与稳定结构，内部双轨代表学习路径，中心星点代表个性化 AI，蓝色负责可信与科技感，金色节点负责记忆点。

## 使用边界

- `BrandMark.vue` 作为共享 SVG 品牌组件，支持浅色和深色两套变体。
- 用于移动端顶栏、移动端开屏、网页顶栏和网页登录面板。
- Agent、课程、提醒等功能图标继续使用 Lucide 图标，避免把品牌标志泛化成普通功能按钮。
- SVG 直接内联，不增加额外图片请求，并保留可选无障碍标题。

## 验证

- 390×844 手机开屏截图检查品牌标志清晰度和与原子球的视觉统一。
- `npm run build:mobile` 通过。
