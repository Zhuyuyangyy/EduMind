# 产品方案 V1.0 实施对照

依据用户提供的 `F:/new/智学星枢_App端产品功能规划与体验设计方案_V1.0.docx`，本轮按文档第 6、8、9、10、15 章实施闭环 Alpha 和受控任务工作区。文档中的竞品、价格假设、招募与外部研究不作为现有产品事实。

## 实施清单

- [x] 五入口：首页、学习、星枢、星图、我的；深海军蓝与青蓝、正文 15–17px，保留已有可靠练习流程。
- [x] 可编辑目标、可选期限、每日时间和状态；首页一个主任务、继续上次、真实记录及上下文入口。
- [x] 资料工作区：文本与 PDF 解析、图片归档与明确 OCR 边界、标签搜索、原文段落、资料删除及手动笔记。
- [x] 来源问答：私有资料检索、原文定位、无依据说明，不让上传内容覆盖应用指令。
- [x] 任务中心：预览、确认、执行、状态、取消、失败重试与 Markdown 产物；不接外部支付或任意桌面控制。
- [x] 学习工作台：路径、讲解模式、真实题库练习、错题及复习安排、可恢复专注计时。
- [x] 真实记录与知识节点状态，样本不足不显示能力增长；记忆可编辑、删除或关闭，偏好与数据导出、反馈入口。
- [x] 服务端会话归属、跨账号隔离、持久化、事务和输入约束；构建、API、浏览器闭环与 Android 包验证。

通知首发采用用户控制的站内到期提醒；系统推送、iOS 签名设备、第三方日历、正式支付和真实用户学习效果实验，需要对应服务或设备后独立验收，不以页面或开关替代真实能力。

实施结果与尚待上线的边界详见 `docs/mobile-product-v1-delivery-2026-10-26.md`；完整规划的所有 P0 与后续路线尚不能标为完成，尤其账号注销和系统通知仍需独立交付。
