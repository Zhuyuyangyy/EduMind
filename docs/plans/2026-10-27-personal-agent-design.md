# 个人 Agent 提醒与学习简报设计

日期：2026-10-27

## 目标

在不新增模型接口或伪造进度的前提下，把现有任务 Agent 变成一个可持续使用的个人学习助手。它根据当前账号的目标、待确认任务、真实专注记录、已完成练习错题和私有资料状态，给出一条可执行建议，并允许用户用快捷问题进入已有学习流程。

## 交互

- 首页增加一张轻量“星枢提醒”卡片，只呈现一条优先建议和一个主操作。
- Agent 专属工作台增加“今天的学习简报”，展示建议、依据、快捷追问和现有任务执行区。
- 追问使用已有页面和 API：开始今日任务、安排专注、回看错题、打开知识库、带着目标问导师。
- 没有足够真实数据时明确显示“还没有足够记录”，不生成掌握度、完成率或虚构进度。

## 数据规则

建议优先级为：逾期复习 → 待确认任务 → 已有目标但没有任务 → 已有资料 → 未设置目标。建议文案和依据都由当前账号工作区计算，不写入服务器；任务确认、计时、练习和 Agent 产物继续使用现有接口。

## 验收

- 新账号能看到设置目标或开始了解自己的建议，不出现虚构数字。
- 有待办、复习或资料时，首页和 Agent 页给出与数据一致的建议及可达操作。
- 快捷追问能进入学习、专注、复习、资料或导师页面。
- 现有 Agent 预览、确认、执行、取消、重试和笔记保存流程不变。
- 320、390、430、1440 宽度无横向溢出，构建与现有浏览器回归通过。
