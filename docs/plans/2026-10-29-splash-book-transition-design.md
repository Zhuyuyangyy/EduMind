# 星枢开屏书本转场

## 目标

点击“进入学习”后，用一个短暂的 3D 书本开合转场把用户带入登录页或首页，让“学习”从品牌语义变成可感知的动作。

## 动效结构

- 使用 Three.js 在开屏上方创建透明 WebGL 过渡层。
- 一本闭合的蓝色封面书从中缝分成左右两页，向外打开。
- 书内加入金色脊线、中心光晕和蓝白粒子；镜头同时向前推进。
- 动画约 1.5 秒，结束后沿用现有登录态路由跳转。
- Three.js 通过动态 import 按点击加载，避免增加普通启动首包体积。
- WebGL 不可用时使用短暂 CSS 退化过渡，仍然可以进入产品。

## 验证

- 移动端开屏点击后进入登录页。
- `prefers-reduced-motion` 仍保留可操作入口。
- `npm run build:mobile` 通过，Three.js 产出独立按需 chunk。
