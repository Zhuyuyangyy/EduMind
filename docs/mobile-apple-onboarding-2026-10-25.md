## 本批交付

按用户指定的简约 Apple 风格调整移动端：浅灰背景、白色分组卡片、系统字体、单一蓝色主操作、轻量导航与安全区。沿用 Vue + Capacitor 和四个底部入口。网页端业务能力作为对齐基准。

本地集成顺序为安全分支 `64ca96d` → 评估边界分支 `f7bcf82`；两者均基于移动端 `b568bb0`。已通过远程完整 SHA 核对这些分支头。没有合并 GitHub PR，没有修改 `main`，没有纳入支付 PR #2，没有更新线上部署。

具体实现：

- 登录与真实注册入口；正常构建不预填演示账号。
- 完整学习需求：身份、方向、基础、经验、近期/长期目标、具体目标、动机、六维自评、每周时间、时段、资源偏好和节奏。
- 四步问卷，以及导师页独立的“制定学习计划”引导入口；引导采集明确标注用途，选择结果回到问卷确认，属于结构化采集，未宣称实现自由文本 AI 访谈。
- 服务端画像保留白名单内的学习需求和分析来源；同账号重登后恢复，模型与规则分析明确区分。自评分数不是测验成绩。
- 提交画像后生成知识路径；路径生成失败时保留已保存画像，允许单独重试，不伪造成功。
- 保留原有导师问答、练习、服务端判分、反馈和成长记录；新增昵称账号保存入口。
- “我的”移除固定学习偏好示例，改为真实档案入口；服务诊断和 API 设置收至可展开区域。
- 网页需求对话的裸请求改为共享 API 客户端，统一地址、认证、CSRF、超时与错误处理。
- 修正规则画像分析把 0 自评分数误当缺省值的问题。
- 修正 Windows 含空格项目目录下 Android 构建脚本无法启动 Gradle 的问题；Android 系统栏与浅色界面配套。
