# AI Design Skills 视觉规则集成

日期：2026-10-28

来源：用户提供的 `F:/new/ai-design-skills-main.zip`。压缩包包含 `landing-page-design` 和 `design-to-motion` 两个技能。本项目采用前者的视觉约束，未把后者的展示视频流程用于产品内交互。

## 采用的规则

- 继续使用单一中文系统字体栈，避免为了英文展示字体增加网络依赖。
- 背景使用平面色，渐变只保留给数据可视化或明确的品牌文本效果；卡片不再用背景渐变制造层次。
- 边框整面使用，卡片和内层控件遵循外层半径减内间距的关系。
- 字号、间距、圆角和动效统一从移动端 token 读取；页面层只组合 token，不继续增加新的颜色来源。
- 动效只改变 transform、opacity、颜色或阴影，并尊重 `prefers-reduced-motion`。
- 空态、加载、错误、焦点和当前导航状态都必须是可操作且可解释的界面状态。

## 不直接采用的规则

`design-to-motion` 面向静态设计展示、MP4 和 GIF 导出，不适合当前 App 的业务交互，因此不在产品页面加入展示循环或视频导出逻辑。Landing page 的转化结构也不覆盖学习工作台；学习页继续以目标、任务、证据和下一步为主路径。

## 本轮调整

移除移动端画布、品牌标记、重点卡片、首页重点区域、个人中心身份卡和个人 Agent 卡片的背景渐变，统一为平面 surface；补充全局文本换行和 reduced-motion 规则，保留现有数据图表与真实状态边界。
