## 二、两个必须先说的事实

### 1. 线上旧构建对外只展示「3D 舞台登录页」

`yx.shushubiye.fun` 当前版本（health 报 v2.0.0）**没有账号/登录系统**：登录端点不存在（`/api/auth/login` → 404），业务 API 完全公开。因此任何人访问看到的「首页」就是右侧登录面板 + 左侧全息舞台——**旧版登录后的平台界面在线上不可见**（无法截图，也不存在于该构建）。

对比结论：**新版与旧版是同一套设计语言**——旧版登录页的 3D 全息舞台（星链圆环、模块标签、智学星枢全息台）在新版登录页完整保留；新版登录后的首页（`local-web-ng-home.png`）是这套语言的延伸：知识宇宙星球轨道 + 右侧智能体卡片 + 底部能力统计带。**桌面端不存在「拉低第一印象」的问题，它已经比线上旧版更完整。**

### 2. 线上 API 无认证且返回真实用户聊天内容（安全问题，建议尽快处理）

`GET https://yx.shushubiye.fun/api/chat/history` **无需任何凭据**即返回历史聊天，内容包括真实个人陈述（「你好，我是计算机本科在校生，主攻编程与生物信息交叉方向，备赛科创项目……」）。`/api/tutoring/history`、`/api/knowledge-path/latest`、`/api/evidence/summary` 同样公开。

- 影响：任何人均可拉取线上全量聊天/辅导记录（隐私暴露）；evidence summary 还暴露 fallbackRate 66% 等内部质量数据。
- 建议：将线上部署升级到含 P4-1A 账号隔离的版本（当前 `feat/mobile-v1` 已有会话/CSRF/账号边界），或在网关层对 `/api/*` 加认证。**这不应等到视觉升级之后。**

## 四、统一设计规范草案（一次性视觉升级的输入）

### 4.1 品牌色板（从桌面端实证提取，两端强制统一）

| 角色 | 色值 | 用途 |
|---|---|---|
| 深空底 | `#07111f` → `#0a1a2f` 渐变 | 全局背景（移动端已用，桌面端星空层同） |
| 星青（主强调） | `#54d6ff` | 主操作、进度、链接、图标主色 |
| 星紫（次强调） | `#7c6cff → #b388ff` | 渐变按钮、AI 相关、知识节点 |
| 暖金（成就） | `#ffcf6b` | 掌握度、连续学习、成就徽章 |
| 文本层级 | `#f2f7fc` / `#a8bdd4` / `#5f7a99` | 标题 / 正文 / 辅助 |
| 卡片 | `rgba(255,255,255,0.045)` + 1px `rgba(84,214,255,0.14)` 边 | 毛玻璃体系（桌面端已有，移动端复用） |

### 4.2 移动端首页主视觉（「今天先学这一件事」）

- **结构**：顶部问候+日期 → **核心学习卡**（今日主题 + 进度环 + 预计时长 + 单一主按钮「开始学习」）→ 迷你知识星图（横向 3–5 节点，当前节点高亮脉冲）→ 次级入口（辅导/成长/自评，小卡）。
- **空状态**（新用户）：保留现有自评引导文案，但升级为**星球插画 + 大标题 + 单按钮**，去掉三卡堆叠感。
- **动效**：进度环 600ms ease-out 绘制；星图节点当前项 2s 呼吸循环；卡片入场 150ms 上浮+淡入。

### 4.3 图标体系（替换字符图标）

- 统一线性图标（24px 网格、1.5px 描边、圆角帽），五枚 tab：今日（日历/星环）、导师（对话星）、成长（上升星轨）、我的（用户环）。
- 禁止再用 `⌂ ✦ ◎` 等 Unicode 字符充当图标（语义不稳定、跨平台渲染不一致）。
- 桌面端导航图标同步换同套线性图标，建立一端识别度。

### 4.4 排版层级（移动端重定）

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| 页面标题 | 22–24px / 600 | 页头 |
| 核心数字 | 30–34px / 700（星青） | 进度%、连续天数、待学数 |
| 卡片标题 | 16–17px / 600 | 模块标题 |
| 正文 | 13–14px / 400（#a8bdd4） | 说明文字 |
| 辅助 | 11–12px / 400（#5f7a99） | 标签、时间戳 |

### 4.5 动效规范（克制且连贯）

- 页面切换：180–240ms 淡入+位移（禁止弹跳）。
- AI 回复：逐字/逐句出现（导师页已有雏形，统一为 24ms/字符节奏）。
- 进度更新：数字滚动 + 进度环补间，500–800ms。
- 知识点展开：高度+透明度过渡 200ms。
- 所有动效遵循 `prefers-reduced-motion`。

### 4.6 桌面/移动统一语言

- 同一色板（§4.1）、同一「星球/星轨」母题（桌面=大星图，移动=迷你星图）、同一圆角（桌面 16px/移动 14px）、同一阴影/发光体系（星青 8% 外发光）。
- 登录/欢迎、AI 导师、学习路径三屏两端同构——用户一眼认出同一产品。
