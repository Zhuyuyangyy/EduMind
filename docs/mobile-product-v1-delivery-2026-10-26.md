## 已落地

| 方案方向 | 本次实现与实际数据来源 |
| --- | --- |
| 五个入口与视觉 | 首页、学习、星枢、星图、我的。深海军蓝、青蓝行动色、系统字体、减少动态效果；保留已有六张引导卡。 |
| 目标与首页 | 目标名称、可选截止日期、每日时间和暂停/完成/归档状态。首页从用户目标与已确认任务清单开始；已有练习支持恢复。首次学习不强制完成完整画像。 |
| 学习工作台 | 现有阶段路径、三种讲解方式、真实题库、服务器判分与学习报告；增加可恢复的专注计时。计时与用户勾选均不作为能力证据。 |
| 资料与笔记 | 私有文本、Markdown、PDF 文字提取、图片归档、标签与原文搜索、逐段定位、手动转录、关联笔记与 Markdown 导出。单份文件限 5 MB，资料工作区限 20 MB。 |
| 来源问答 | 关键词匹配的原文摘录，显示真实段落及 PDF 页码；当前使用可解释的抽取式检索，不标为模型推理或生产级语义检索。未找到依据时明确说明。 |
| 星枢任务 | 自然语言请求、三个模板、目标/资料授权、计划预览、确认、执行状态、取消、失败或中断重试、规则/模型标记、产物与笔记保存。确认前不产生任务内容；重复确认不重复生成。 |
| 任务安排 | 规则任务步骤的建议总时长符合用户选择的每日预算；生成产物作为草稿，建议时长不冒充已学习时长。 |
| 错题与复习 | 仅从已完成练习的服务器作答记录提取错题，读取原始解释、手动修正错因、选择复习间隔并重新练习。未完成会话的答案继续保密。 |
| 记忆与提醒 | 明确保存的目标及手动偏好可查看、修改、删除或暂停。提醒为站内到期事项，支持提醒时间、安静时段与关闭。 |
| 数据控制 | 资料删除同步移除关联笔记和引用任务产物；提供学习工作区 JSON、笔记与产物 Markdown 导出，反馈记录按账号保存。 |
| 数据安全 | 所有工作区接口使用服务端会话归属；外来账号 ID 不参与授权。JSON 用于本地演示，生产沿用 MySQL 门禁；新工作区在 MySQL 中用事务与独占行锁串行更新。 |
